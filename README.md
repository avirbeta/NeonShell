# Neon Shell 1.0

**Neon Shell** — неоновая игровая оболочка для Windows 10: заменяет стандартный
рабочий стол (Windows-оболочка скрывается, при выходе восстанавливается).

- Разработчик: **Vizor**
- Платформа: Windows 10/11 x64, .NET 8 WPF
- Стиль: неоновый (циан/маджента, свечение, тёмный фон)

## Что делает

- **Прячет стандартный рабочий стол Windows** (системная панель задач и значки
  скрываются обратимо — explorer.exe не завершается)
- **Неоновый рабочий стол**: 5 неоновых обоев со свечением, значки с подсветкой,
  перетаскивание, контекстные меню, создание папок/ярлыков
- **Неоновая панель задач**: кнопка Start (геймпад), закреплённые, открытые окна,
  трей (сеть/звук/батарея), часы, календарь, автоскрытие, «показать рабочий стол»
- **Меню с играми**: вкладка «Игры» — Steam + Epic + вручную, обложки, запуск;
  при поиске неоновый акцент подстраивается под цвет обложки игры
- **Приложения**: все установленные программы + недавние
- **Центр управления**: громкость, сеть, батарея, быстрые действия, питание
- **Параметры Neon**: неоновые схемы (6 шт.), обои, размер значков, панель, автозапуск
- **Уведомления** с неоновым свечением
- **Выход в Windows**: ПКМ по трею / панели / меню «Выйти в Windows» — стандартный
  рабочий стол полностью восстанавливается (при необходимости explorer перезапускается)

## Безопасность

- Не заменяет explorer.exe, не трогает загрузчик, службы и реестр (кроме
  пользовательского ключа автозапуска)
- При 3+ сбоях за сутки автозапуск отключается автоматически
- Безопасный режим: `NeonShell.exe --safemode`
- Аварийное восстановление: Ctrl+Shift+Esc → завершить `NeonShell` → перезапустить
  `explorer.exe` (Файл → Новая задача → `explorer`)

## Сборка

Нужен .NET 8 SDK:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Результат: `dist\portable\NeonShell.exe` (один файл), `dist\self-contained\`,
`dist\framework-dependent\`.

## Запуск

```
NeonShell.exe
NeonShell.exe --safemode    (безопасный режим)
NeonShell.exe --autotest    (тест: 8 секунд и выход)
```

Данные: `%APPDATA%\NeonShell\` (настройки, рабочий стол, обои, журналы).
